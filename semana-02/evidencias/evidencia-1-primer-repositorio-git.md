# Evidencia 1 — Primer repositorio con Git

1. **URL del repositorio en GitHub:** https://github.com/luis-codex/cern-preparation-program

2. **Qué aprendí:** a llevar un flujo completo de Git de principio a fin: preparar
   cambios con `add`, registrarlos con `commit`, revisar el historial con `log` y
   sincronizarlos con GitHub mediante `push`. También reforcé la relación entre el
   repositorio local y el remoto (`origin`).

3. **Comando que me resultó más útil:** `git log --oneline`, porque permite ver de
   un vistazo el historial completo de cambios y entender la evolución del proyecto.

4. **Dificultad encontrada:** al principio no tenía claro cuándo un archivo pasa de
   "sin seguimiento" a "en stage" a "confirmado"; revisar `git status` después de
   cada paso ayudó a entender el flujo.
