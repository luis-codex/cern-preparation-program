# Ejercicio — Primer repositorio con Git

Práctica de los comandos básicos de Git usando este mismo repositorio.

## Pasos realizados

1. Verificar el estado del repositorio: `git status`
2. Agregar cambios al área de stage: `git add <archivo>`
3. Registrar cambios con un mensaje descriptivo: `git commit -m "mensaje"`
4. Revisar el historial de commits: `git log --oneline`
5. Confirmar la conexión con el remoto en GitHub: `git remote -v`
6. Subir los cambios: `git push`

## Comandos practicados

| Comando | Para qué sirve |
|---|---|
| `git init` | Inicializa un repositorio local |
| `git status` | Muestra el estado de los archivos (sin seguimiento, modificados, en stage) |
| `git add` | Mueve cambios al área de stage antes de confirmarlos |
| `git commit -m` | Registra un punto en el historial con un mensaje |
| `git log --oneline` | Lista el historial de commits de forma resumida |
| `git remote add origin` | Conecta el repositorio local con uno remoto en GitHub |
| `git push` | Envía los commits locales al repositorio remoto |
